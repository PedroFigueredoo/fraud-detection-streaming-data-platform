SQL Analytics

## Goal

Provide advanced analytical SQL queries for fraud monitoring and business analysis.

## Planned Views

- fraud rate by month;
- fraud rate by age group;
- fraud rate by employment status;
- moving average of fraud rate;
- score percentile by group;
- top risky applications;
- false positive rate by group.

## SQL Techniques

- CTEs;
- window functions;
- ranking;
- moving averages;
- percentiles;
- conditional aggregation.
